# Prueba del personaje Demo

1. Abre Inicio y entra a Demo.
2. Escribe: `me gusta el azul`. Luego abre Configuración del chat → Caja de memoria y comprueba la memoria automática.
3. Añade una tarjeta llamada `Relación` y vuelve al chat.
4. Cambia el perfil inspirado a EpicTale Large y revisa temperatura/DRY/longitud.
5. Con el backend apagado, usa el modo `Automático · servidor + respaldo offline`: la app debe seguir respondiendo.
6. Enciende el backend y comprueba desde Ajustes el estado del servidor.
7. Crea un chat nuevo: el anterior debe quedar archivado.
8. Prueba la voz 🔊 sobre una respuesta del personaje.

Mack no debe añadirse hasta que estas rutas sean estables.
