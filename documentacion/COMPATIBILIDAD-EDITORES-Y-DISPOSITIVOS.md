# Compatibilidad

## Editores

El cliente usa HTML/CSS/JavaScript ES Modules y puede editarse sin compilador en VS Code, Antigravity, Acode, Spck u otro editor que sirva archivos por HTTP.

El backend Python puede editarse en VS Code/Antigravity y cualquier editor móvil de texto; para ejecutarlo se necesita Python en una PC/servidor, no en el teléfono.

## Dispositivos objetivo

- HONOR X7d 8/256
- HONOR X6
- Samsung Galaxy A21s
- Samsung Galaxy A32
- ZTE Blade A7s 2020 / A7020
- PC HP y ASUS

La interfaz es mobile-first desde 320 px. El modelo grande corre en servidores externos, por lo que los teléfonos no necesitan RAM/VRAM para cargar el LLM.
